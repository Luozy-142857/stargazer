# 指标定义与临床对应

本文说明每个输出的**确切含义、公式、以及它在临床上能对上什么**。
任何对外材料都应引用这里的口径，不要另起说法。

---

## 1. 角度与棱镜度

```
1 棱镜度 (PD) = 100 cm 处偏移 1 cm = atan(0.01) ≈ 0.5729°
PD = 100 · tan(θ)
```

常用换算：

| 角度 | 棱镜度 |
|---|---|
| 1° | 1.75 PD |
| 1.5° | 2.62 PD |
| 5° | 8.75 PD |
| 10° | 17.63 PD |
| 13° | 23.09 PD |

**为什么坚持用 PD 汇报**：临床上所有斜视量都用 PD（遮盖试验、棱镜排、手术量）。
报「度」会让医生每次心算一遍，而且容易和角膜映光法的「1mm ≈ 7°」混淆。

## 2. 偏斜角（核心指标）

### 定义

对每只眼独立计算：

```
θ = atan2(pred_x, d) − atan2(target_x, d)      （水平）
φ = atan2(pred_y, d) − atan2(target_y, d)      （垂直）
```

- `pred` = 该眼校准模型当前输出的注视点（屏幕毫米）
- `target` = 当前靶点（屏幕毫米）
- `d` = 观看距离（毫米）

取两眼中 |θ| 较大的一只作为「偏斜眼」，其值即偏斜量，符号表示方向。

### 为什么这样定义

- **不用两眼视轴夹角**。两眼注视同一点时本来就有会聚角（50 cm、63 mm 瞳距下约 7.2° ≈ 12.5 PD），
  两眼差值在正位眼身上也会读出十几 PD。必须**逐眼对靶**比，正常会聚才不会被算成偏斜。
- **共模误差自动抵消**。头位、镜头畸变、屏幕几何这些误差对两眼相同，逐眼对靶比时相互抵消。
  这是「相对偏斜角能做到 1.5°，而绝对注视点不能」的根本原因。

### 可测范围

受校准点阵覆盖范围限制，约 **±13°（±22 PD）**。超出的偏斜会因回归外推而**被低估**。

这不是可以靠调参解决的——是回归模型的本性。若要覆盖大角度，必须扩大校准视野（更大屏幕/更近距离），
而那会牺牲中心区的精度。结论：**这个内核的适用区间是 ±20 PD 以内**，正好覆盖间歇性外斜视、
集合不足、术后残余。大角度恒定性斜视不在适用范围内。

### 符号约定（未确证）

当前输出的符号是「图像坐标系」的：正值 = 该眼估计视轴落在靶点的图像右侧。

尚未映射成内斜 / 外斜。**因为符号取决于摄像头是否镜像、以及「图像左侧」对应受试者哪只眼。**
必须在验证阶段用已知方向的棱镜（如右眼前加 base-out）确认一次，再固化成常量。
在那之前，任何「内斜/外斜」的推断都不要写进报告。

## 3. 偏斜事件（间歇性外斜视的主指标）

```
阈值：|θ| ≥ 3 PD
最短持续：200 ms
最小间隔：120 ms
```

输出：事件次数、总占比（duty）、平均/最长持续时间、平均/最大幅度。

### 为什么这个比「平均角度」重要

间歇性外斜视的定义就是**偏斜时有时无**。用整段平均会得到 2 PD 这种没有信息量的数。
真正有临床意义的是：

- **出现频率**：一天里有多少比例时间在外斜
- **幅度**：一旦出现，偏多少
- **恢复能力**：能否自己回到正位（融合控制）

这三个量分别对应治疗随访的三个观察点。平均角度一个都回答不了。

## 4. BCEA（注视稳定性）

### 定义

注视散点的协方差矩阵特征值 σ₁ ≥ σ₂，则

```
A(p) = −2π · σ₁ · σ₂ · ln(1 − p)
```

- `p = 0.632` 时退化为经典 BCEA（Steinman 1965 的定义）
- `p = 0.6827` 时对应 ±1σ 椭圆（本项目默认报这个，标注为 BCEA₁σ）

实现里还同时给出 `pctWithin1` / `pctWithin2`（落在 1°/2° 内的样本占比），
因为面积指标对离群点敏感，占比指标更稳健，两个一起看。

### 临床对应

BCEA 是微视野计（microperimetry）的标准注视稳定性指标，文献阈值大致：

| BCEA₁σ | 判读 |
|---|---|
| < 1 deg² | 稳定 |
| 1–3 deg² | 相对不稳定 |
| > 3 deg² | 不稳定 |

注意：这些阈值来自黄斑病变人群，用在斜视儿童上只能作参考，不能直接套。

## 5. 追随增益

以靶点角度为自变量、眼角度为因变量做线性回归，斜率即增益：

```
gain = Cov(眼, 靶) / Var(靶)      理想 ≈ 1
```

同时给出：
- `rmseDeg`：按最优增益对齐后的残差（反映**平滑度**，不会被低增益污染）
- `lagMs`：互相关峰位置（反映**延迟**）

### 帧率约束

30 fps 下，一个 20 ms 的扫视只有 1 帧。所以：

- ✅ 可以测：增益、滞后、慢相漂移、追赶性扫视的**次数**
- ❌ 不能测：扫视幅度/峰速的精确值、扫视潜伏期

要测扫视细节必须 60 fps 摄像头，并在协议里加阶跃刺激。

## 6. 重复性与 MDC

没有金标准（棱镜/临床对照）时，这是唯一能拿到的量化指标，而它恰好决定「能不能跟踪训练效果」。

同一姿势连测 N 轮，每轮取读数中位数，跨轮算标准差 SD：

```
MDC95 = 1.96 × √2 × SD
```

- `1.96`：95% 置信
- `√2`：比较两次测量，两次各自的噪声都会进来
- 含义：**两次测量之差要超过 MDC95，才可能反映真实变化**

取 k 轮平均后再比较，MDC95 降为 `MDC95 / √k`。

**本项目实测**（同一受试者 5 轮，6 维眼宽归一化模型）：
轮间 SD ≈ 1.4 PD，单次 MDC95 ≈ 3.9 PD，**3 轮取中位后 ≈ 2.25 PD（1.29°）**。
详见 [`RESULTS.md`](RESULTS.md)。

判读：≤4 PD 可做随访趋势；4–8 PD 只能判断"有没有明显变差"；>8 PD 只能分档。

注意：MDC 只刻画**精密度**（随机散），不反映**准确度**（系统偏）。
偏倚在前后对比中会抵消，所以纵向结论主要受 MDC 约束；
但绝对值的正确性仍需与棱镜遮盖试验对照才能确认。

## 7. 故意没有做的指标

| 指标 | 为什么不做 |
|---|---|
| **单眼抑制时长** | 摄像头物理上测不到。抑制是视皮层的双眼竞争结果，没有外周可见信号。替代方案：① 双眼分视下的对比度平衡点（需要红青/快门/VR 呈现）② 随机点立体图测立体视锐度（纯行为学，不需要眼动）③ 偏斜眼注视丢失时长（只是代理量，不是抑制本身） |
| **立体视锐度** | 需要分视呈现，属于游戏层，不属于测量内核 |
| **融合范围** | 需要棱镜渐变或分视，同上 |
| **瞳孔直径** | 可见光下瞳孔边缘检测不可靠（无虹膜背光），误差比指标本身大 |
| **绝对注视点精度** | 能算，但不要报。普通摄像头 + 可见光，2–4° 是现实值，报了只会被质疑 |

## 8. 「1.5°」应该怎么表述

不要写「检测精度 1.5°」。写这三句：

> 1. 单眼校准的**留一点交叉验证误差**中位数为 X°（n=Y 名受试者，每例 Z 次扣点重拟合）。
> 2. 与棱镜遮盖试验对照，**95% 一致性界限**为 ±Z PD（±W°），偏倚 bias = B PD。
> 3. 适用区间为 ±20 PD，超出范围偏低估计。

这三句都可复现、可审计，而且比一个孤立数字更有说服力。
第 2 句的产出方式见 [`VALIDATION-PROTOCOL.md`](VALIDATION-PROTOCOL.md)。
